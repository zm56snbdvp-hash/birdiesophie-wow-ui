# Birdiesophie UI — Master Briefing

## Project

World of Warcraft: The Burning Crusade Classic — Night Elf Druid **Birdiesophie**. The interface belongs to the Birdie & Breakfast universe.

## Vision

A calm, premium interface for a super-ultrawide curved display. It combines Night Elf/Druid atmosphere with Birdie & Breakfast: deep forest green, graphite, warm gold, cream typography and very little visual noise.

## Design principles

- **Combat first:** everything critical stays near the center.
- **Intentional ultrawide use:** outer areas contain secondary information only.
- **One system:** a clean, coherent interface rather than an addon wall.
- **Druid first:** forms, resources, procs and cooldowns define the information hierarchy.
- **Subtle brand:** recognizably Birdie & Breakfast, never advertising.
- **Expandable:** relaxed leveling now, raid-ready later without a rebuild.

## Screen zones

### Center — Combat Core

Character, target/boss, cast bars, WeakAura HUD, resources and critical cooldowns.

### Bottom center — The Bag

Compact action bars. Cat, Bear, Travel and Caster follow consistent ergonomic logic.

### Left — Clubhouse Comms

Chat, party/guild and optional quest information.

### Right — Caddie Zone

Details!, threat, damage/healing and later raid or utility information.

### Outer ultrawide space

No time-critical information. Context, analysis and resting UI elements only.

## Druid HUD

The HUD is nearly invisible outside combat. It reveals only relevant information:

- current form
- active resource
- important buffs and debuffs
- procs
- defensive and offensive cooldowns
- target state
- later variants for Feral, Balance and Restoration

## Birdie language

- Cat — offensive club
- Bear — defensive club
- Travel — movement
- Caster — clubhouse
- Optional microcopy: `NEXT TEE →` and `WELCOME TO THE CLUBHOUSE.`

## Build sequence

1. Confirm screen specification.
2. Define the pixel and anchor layout.
3. Build the ElvUI structure and profile values.
4. Specify the Druid WeakAura HUD.
5. Define action-bar and form logic.
6. Test and tune in game.
